# Vesora Pay Flutter prototype

Demo wallet interface with a simulated balance, local demo top-up, wallet/activity/profile tabs.

## Run
Install Flutter SDK, then run `flutter pub get` and `flutter run` from this folder.

## Important
This is a prototype only. It does not hold funds, issue cards, process deposits, or send real payments. Real money functionality needs a payment provider/issuer, secure backend, identity verification, and regulatory compliance.
